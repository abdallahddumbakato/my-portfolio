## 🌟 Overview

A modern, responsive portfolio website showcasing my journey as a Platform & AI Systems Engineer. Built with Next.js and Tailwind CSS, this portfolio demonstrates my expertise in AI infrastructure, LLM systems, and cloud platform engineering through interactive UI components and seamless user experience.
